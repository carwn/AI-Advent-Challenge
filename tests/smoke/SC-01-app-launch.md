# SC-01: Запуск приложения — главный экран виден

**Приоритет**: P0  
**Экран старта**: холодный запуск  
**Текстовый ввод**: нет

## Предусловия
- Приложение установлено
- Свежий запуск (terminate если уже запущено)

## Шаги

| # | Действие | Тип | Ожидаемый результат |
|---|----------|-----|---------------------|
| 1 | Запустить приложение | TAP | — |
| 2 | Ждать завершения анимации запуска | WAIT | Индикатор загрузки исчез |
| 3 | Сделать скриншот начального экрана | SCREENSHOT | — |
| 4 | Проверить наличие главного экрана | VERIFY | Виден список диалогов (или пустое состояние с кнопкой создания) |
| 5 | Проверить кнопку создания нового диалога | VERIFY | Кнопка "+" или аналогичная присутствует в навигационной панели |

## Ожидаемый финальный результат
Отображается главный экран со списком диалогов (или пустым состоянием). Навигационная панель содержит кнопку создания нового диалога.

## Критерий провала
- Приложение крашнуло при запуске
- Экран пустой или показывает ошибку
- Нет возможности создать новый диалог
