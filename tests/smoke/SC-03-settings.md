# SC-03: Открытие настроек и возврат

**Приоритет**: P1  
**Экран старта**: главный список диалогов  
**Текстовый ввод**: нет

## Предусловия
- Приложение запущено, виден главный экран

## Шаги

| # | Действие | Тип | Ожидаемый результат |
|---|----------|-----|---------------------|
| 1 | Сделать скриншот стартового состояния | SCREENSHOT | — |
| 2 | Тапнуть иконку настроек (шестерёнка / gear) в навбаре | TAP | Открылся экран Settings |
| 3 | Проверить наличие секции LLM Провайдер | VERIFY | Видна секция выбора модели |
| 4 | Проверить наличие секции API ключа | VERIFY | Видна секция ProxyAPI.ru |
| 5 | Сделать скриншот экрана настроек | SCREENSHOT | — |
| 6 | Тапнуть Done / Close / кнопку закрытия | BACK | Закрылся экран настроек |
| 7 | Проверить возврат на главный экран | VERIFY | Виден список диалогов |
| 8 | Сделать скриншот финального состояния | SCREENSHOT | — |

## Ожидаемый финальный результат
Экран настроек открылся, содержит секции выбора модели и API ключа. После закрытия — снова виден главный экран.

## Критерий провала
- Кнопка настроек не найдена
- Экран настроек не открылся
- Секции настроек отсутствуют
- Не удалось закрыть экран настроек
